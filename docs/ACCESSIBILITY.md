# Accessibility notes

- Semantic headings, product articles, labeled controls, and an explicit catalog landmark.
- Keyboard shortcut for search, Escape-to-close behavior, and focus return after drawer dismissal.
- Live regions announce result counts and cart actions.
- Buttons use visible focus defaults and descriptive quantity labels.
- Motion is reduced when the operating system requests reduced motion.
- Text and primary controls maintain strong contrast against the neutral palette.

Production follow-up would include automated axe checks and testing with VoiceOver, NVDA, keyboard-only navigation, zoom, and forced-colors mode.
